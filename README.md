# Reps

Aplicación web para registrar entrenamientos de gimnasio, incluyendo ejercicios, series, repeticiones, peso y fecha.

## Instalación

### Ubuntu / Linux

```bash
sudo apt update
sudo apt install golang-go
```

### Windows

Abrir PowerShell y ejecutar:

```powershell
winget install GoLang.Go
```

Para comprobar que Go se instaló correctamente:

```bash
go version
```

## Ejecución

Dentro de la carpeta del proyecto ejecutar:

```bash
go run main.go
```

Luego abrir en el navegador:

```text
http://localhost:8080
```
