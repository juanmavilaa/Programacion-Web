# Reps

Reps es un trackeador de ejercicios de gimnasio que
permite registrar clientes y sus entrenamientos (ejercicio, series, repeticiones,
peso y fecha). 

Actualmente tenemos la base de datos (schema, queries y el código generado con sqlc) ya definido

## Requisitos

- Go 1.22 o superior

## Instalar Go

Ubuntu/Linux:

```bash
sudo apt install golang-go
```

Windows (PowerShell):

```powershell
winget install GoLang.Go
```

## Correr el servidor

```bash
go run main.go
```

Entrar a `http://localhost:8080`.
